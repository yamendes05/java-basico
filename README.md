# Estudos de Java

Repositório destinado a exemplos, exercícios e práticas de programação em Java.

## Objetivo
Registrar a evolução nos fundamentos da linguagem e manter exemplos que possam ser consultados durante os estudos.

## Conteúdos
Os exemplos deste repositório podem abordar fundamentos da linguagem, orientação a objetos, estruturas de controle, coleções e resolução de exercícios.

> A lista de conteúdos será atualizada conforme novos exercícios e exemplos forem adicionados.

## Tecnologia
- Java

## Como executar
Clone o repositório:
```bash
git clone https://github.com/yamendes05/java-basico.git
```
Abra o projeto em uma IDE Java ou compile e execute a classe que contém o método `main`.
